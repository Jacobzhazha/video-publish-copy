# Python JSON 排版演示

## B站
### 标题
Python格式化JSON：显示中文与嵌套缩进
### 简介
演示 JSON 重新排版后，中文直接显示，嵌套层级有缩进，示例对象的字段和值保持不变。
用 Python 自带的 json 模块，先通过 json.loads 解析字符串，再用 json.dumps 设置 ensure_ascii=False 和 indent=2，重新排版一行 JSON。
这个示例只改变空白表示。遇到不合法的 JSON，要先修语法，格式化不会自动修数据。
