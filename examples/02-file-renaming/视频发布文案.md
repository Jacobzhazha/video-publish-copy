# 空白文件批量命名演示

## B站
### 标题
批量命名前先预览：用3个空文件演示
### 简介
3 个空白占位文件先生成改名清单，再复制到另一个目录，原文件保留。
演示目录里的 a.jpg、b.jpg、c.jpg 先按原文件名排序，对应生成 photo-001.jpg、photo-002.jpg、photo-003.jpg 的改名清单。预览清单后，再按新名字复制。
这里的 jpg 都是空白占位文件。遇到目标文件同名就停止，不覆盖。
