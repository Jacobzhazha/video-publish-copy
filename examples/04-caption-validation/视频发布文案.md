# 三平台发布文案结构检查

## B站
### 标题
三平台文案怎么查：小节、标签和重复标题
### 简介
本地 Python 检查器能检查文案结构，文案是否符合原素材仍要逐条看。
同一条视频，B站写搜索词和结论，视频号写具体成果，抖音先给结果。写完后检查平台小节、B站标签数量、话题格式和重复标题；把封面标题传给检查器，也能检查发布标题是否照抄封面。
信息没补齐就保留待补标记，最终稿检查会拦住它。结构检查通过后，再对照原素材核对文案。
### 标签
发布文案，B站文案，视频号文案，抖音文案，Python，结构检查，标签数量，话题格式，重复标题
